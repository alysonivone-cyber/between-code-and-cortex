# Between Code & Cortex — Portfolio

## Installation dans VS Code (Windows / PowerShell)

1. Extraire le ZIP dans `Documents/CREA 2027/`.
2. Ouvrir le dossier `between-code-and-cortex-final` dans VS Code.
3. Exécuter :

```powershell
npm.cmd install
npm.cmd run dev
```

4. Ouvrir l'URL indiquée par Vite (souvent http://localhost:5173/).

Si vous voulez conserver votre dossier actuel, faites une copie de sauvegarde puis remplacez `src/main.jsx`, `src/style.css` et ajoutez les fichiers du dossier `public` (images et PDF).
